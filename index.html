02 / FIREPOWER

四档火力，逐级失控

不是四个 EQ 预设，而是四条独立处理链。每一档都重新做削波、饱和、压缩与限幅。

!

响度不是免费的。越往上，动态越小、失真越多、耳朵越累。建议先用「普通炸麦版」试听，再逐级加码。

04 / FIELD MANUAL

使用说明

三步完成。没有登录、没有队列、没有「正在上传」。

  1. 01

    放入音源

    拖入 MP3 / WAV / FLAC 等文件，或点选内置示例曲。建议先试 30 秒以内的片段。

  2. 02

    选一档火力

    普通炸麦版保留最多动态；鞭炮版最响、最碎、最不讲理。点「开始炸麦」渲染。

  3. 03

    试听并导出

    用 A/B 对比原曲，确认没有过度失真，再选择格式导出。四档可一键打包。

为什么导出的歌这么响？

四档分别把综合响度推到约 -8 / -6 / -4.5 / -3.5 LUFS，并用真峰值限幅压住天花板。这是母带级的响度，普通播放器会显得非常炸。

会上传我的歌吗？

不会。页面是纯静态文件，没有后端接口。音频在浏览器内解码、处理、编码，刷新页面即清空。

支持多长的音频？

取决于设备内存。建议单次不超过 5 分钟；更长的音频请先剪成片段。处理时页面会短暂占用较多 CPU。

OGG 导出是灰色的？

OGG 使用 WebCodecs 的 Opus 编码器，目前主要在 Chrome / Edge 中可用。其他浏览器请选择 WAV、MP3 或 FLAC。

「极致纯响鞭炮炸麦版」里噼里啪啦的声音是什么？

在常规炸麦链之外，额外叠加了一层由原曲瞬态触发的合成鞭炮：高频爆裂、低频闷响，以及随节奏加密的噼啪声。它不是采样，是实时合成的。
